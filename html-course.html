Lesson 1: Welcome & Introduction to HTML

1. Welcome

Hello everyone! Welcome to our first coding class. For the next 12 weeks, we will learn how to build real websites from zero. By the end of this course, each of you will have your own online portfolio. So today, relax, follow me step by step, and enjoy the process.

2. What is the Web?

Before we start coding, let’s understand something important: What is the internet?
The internet is a global network of computers that communicate with each other. A website is simply a file stored on another computer called a server. When you visit a website, your browser (Chrome, Firefox, Edge) requests the file and shows it to you.

Websites are built using three main languages:

  • HTML – gives structure (the skeleton)
  • CSS – gives style (colors, layout, beauty)
  • JavaScript – adds functionality (movement, logic, interactivity)

3. Activity

Can you mention any website you visited today? Google? TikTok? YouTube?
All of these websites use HTML, CSS, and JavaScript.

SECTION 1: INTRODUCTION TO HTML

Now let’s start with our first language: HTML.
HTML stands for HyperText Markup Language. It is the language that builds the structure of every webpage.

Think of HTML like building a house. The walls, the floor, the windows — that is HTML. It doesn’t look beautiful yet, but it forms the structure.

💻 Open the Coding Environment

Today we learn how to create our first web page using HTML.
We will use an online editor that works in any browser — no signup required.

Go to: TryIt Editor

📘 What to Teach Step-by-Step

Step 1 — Open the TryIt Editor

Guide students to open the URL. Explain: Left side → code, Right side → preview (output).

Step 2 — Replace Starter Text

<!DOCTYPE html>
<html>
<head>
  <title>My First Webpage</title>
</head>
<body>
  <h1>Hello World!</h1>
  <p>This is my first website using HTML.</p>
</body>
</html>

Step 3 — Explain the HTML Structure

  • <!DOCTYPE html> → tells the browser this is HTML
  • <html> → main container
  • <head> → metadata
  • <title> → browser tab name
  • <body> → visible content

Step 4 — Add an Image

<img src="https://via.placeholder.com/200" alt="Sample Image">

Step 5 — Add a Link

<a href="https://google.com" target="_blank">Visit Google</a>
