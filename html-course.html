Hello everyone! Welcome to our first coding class. For the next 12 weeks, we will learn how to build real websites from zero. By the end of this course, each of you will have your own online portfolio. So today, relax, follow me step by step, and enjoy the process.

What is the Web?

The internet is a global network of computers that communicate with each other. A website is simply a file stored on another computer called a server. When you visit a website, your browser requests the file and shows it to you.

  • HTML – structure
  • CSS – style
  • JavaScript – interactivity

Activity
